# EREN–ILDO Reproducibility Code (English), Version 09

This package carries forward the Version 08 code bundle in BASE_V08 and adds FOLLOW_ON_36_RUNS with code snapshots, inputs, run plans, environment records, and provenance for the manuscript’s separately reported 36-run follow-on extension. See FOLLOW_ON_36_RUNS/README.md and the corresponding README in the supplementary package.

The full terminal/checkpoint evidence and audits for the new extension are preserved in the supplementary package’s FOLLOW_ON_36_RUNS/run_archives directory. Do not interpret right-censored runs as complete Pareto enumerations.
