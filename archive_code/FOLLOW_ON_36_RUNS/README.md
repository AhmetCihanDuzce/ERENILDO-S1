# Follow-on code, inputs, and provenance

These files extend the reproducibility materials in BASE_V08 for the 36 follow-on executions summarized in the companion supplementary package. Each cohort subfolder preserves the archived runner/source snapshots (where supplied), input files, provenance, run plan, environment record, and source/hash manifests. Original execution logs, checkpoints, terminal records, and audits are in the supplementary package’s nested run archives.

The cohorts are not a rerun of the full historical panel. Six KP50 searches completed; the other 30 executions were right-censored. Point counts for censored runs are partial progress. The AP p=4 input is synthetic (NumPy PCG64 seed 2026102301), and TSP20 uses one registered replicate.

The archived run scripts are evidence of the execution protocol, not a claim that every ZIP is a turnkey environment. Use the pinned package/version information and environment snapshots in each cohort; solver/library versions and operating-system details are recorded in the cohort metadata where available.
