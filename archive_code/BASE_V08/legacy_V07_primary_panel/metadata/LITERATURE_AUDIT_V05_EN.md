the scope of the claims used in the revised manuscript.

The literature does not support claiming that weighted lexicographic aggregation
or eliminating one solver call is new in itself. The revised contribution is
the stated PEA-specific implementation and computational analysis. Adding a
reference does not imply that the associated algorithm was run in this panel.
